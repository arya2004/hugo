# Proof of Contribution — current product

A repository is a project with a dedicated Arc Testnet treasury and a permanent combined reward cap chosen at creation. Owners have a separate workspace with registration, balance, donation form, Start Funding and Stop Funding. Anyone can donate, even while stopped. Only merges during an active funding interval are eligible; stopping never cancels reserved shares.

Immediately evaluate verified merged code using 0G, persist scores/explanations/evidence, and calculate a deterministic donation-aware reward bounded by funds and the immutable cap. Split it among eligible code contributors; reviewers get zero. No funding periods or manual allocation approvals.

Registered contributors have a server-verified GitHub numeric identity linked to a thirdweb embedded wallet before allocation. They receive automatic Arc payments without logging in again. Unregistered contributors need no account before contributing: their individual shares remain reserved until thirdweb GitHub login and a claim. Mixed recipients settle independently. The service relays transactions. Duplicate requests cannot produce duplicate payments.

Contributor UI: GitHub login, automatically created embedded wallet, unclaimed reserved shares and claim/check-payment buttons. No wallet-request comments, email delivery, username-based verification, public claimant mapping or public individual reward amounts. Public onchain transfers remain visible. Public Arkiv records show eligibility and settlement references.

Pages: home; owner projects; register repo with immutable cap; project funds/reward statuses; owner funding controls; contributor claims; shared-address donation page; live public attestations. Development preview is explicitly labelled sample data and never claims real integrations.
