# Contributing to Hugo

Thanks for helping improve Hugo. Bug reports, documentation, and focused pull requests are welcome.

## Get started

1. Read the [README](README.md) for local setup and API credentials.
2. Open an issue for a bug or a substantial change so the approach can be discussed.
3. Fork the repository, create a branch, and make a focused change.
4. For application changes, run the relevant checks from `app/`:

   ```sh
   npm run lint
   npm run typecheck
   npm test
   ```

5. Open a pull request explaining the change, why it is needed, and how you verified it. Include screenshots for visible UI changes. Mention any configuration or database changes.

Use testnet assets. Never commit API keys, private keys, tokens, or real environment files. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). By contributing, you agree that your contributions are provided under the [MIT license](LICENSE).
