# Security

Hugo is a testnet proof of concept. It trusts post-merge workflow evidence and assumes the registrant owns the repository. Do not use it with valuable assets without an independent security review.

To report a suspected vulnerability, use [GitHub's private vulnerability reporting](https://github.com/arya2004/poc-codex-blueprint/security/advisories/new) if available. If private reporting is unavailable, contact a maintainer through their GitHub profile. Include reproduction steps and affected components; do not disclose secrets or exploit details in a public issue. Maintainers will review reports as time permits; no response or remediation deadline is guaranteed.
